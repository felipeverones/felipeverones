- 🔍 Build **RAG systems** end-to-end: vector databases, embeddings, and contextual retrieval workflows — including a system that cut document retrieval time by ~72%.
- ⚙️ Optimize LLM quality, latency, and cost through context pre-filtering, retrieval constraints, and observability-driven monitoring.
- 🖼️ Apply Computer Vision and multimodal models — from CNN-based object detection to OCR and multimodal data extraction pipelines.
- 🎓 B.Sc. in Computer Engineering (UFSC) — thesis on deep learning-based road damage detection, open-sourced in [yololit-RDD](https://github.com/felipeverones/yololit-RDD).
